## Ответы на контрольные вопросы

### 1. Что такое регрессионное тестирование?

Регрессионное тестирование — это повторный запуск ранее проверенных тестов после внесения изменений в программу, чтобы убедиться, что новые правки не нарушили уже существующее поведение. Оно позволяет обнаруживать ошибки, возникающие в уже работающих частях системы при внесении исправлений или новых функций.

### 2. Для чего используются GitHub Actions?

GitHub Actions используются для автоматизации различных процессов разработки, в том числе сборки проекта, запуска тестов, проверки качества кода и публикации результатов. В данной работе они применяются для автоматического регрессионного тестирования при событиях push и pull request в ветку master.
